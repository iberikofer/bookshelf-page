## 📖 About the Project

**Bookshelf** is an interactive web application designed for exploring bestselling books, discovering categories, viewing detailed book information, and managing a personal reading/shopping list.

### Key Features:
- **Best Sellers Overview:** Browse top books grouped by New York Times bestseller categories with quick-view modals.
- **Category Filter:** Explore curated book lists sorted by genre.
- **Book Modal Window:** Interactive details popup with direct shopping links (Amazon, Apple Books, Bookshop) and smooth animations.
- **Shopping List:** Add and remove books with persistent local storage and pagination.
- **Theme Switcher:** Seamless Dark and Light mode support.
- **Charity Slider:** "Support Ukraine" foundation slider.

### Tech Stack:
- **Core:** HTML5, CSS3, JavaScript (ES6+)
- **Styling:** Sass / SCSS, BEM methodology
- **Bundler:** Parcel
- **Libraries:** Axios, Notiflix, TUI Pagination, Swiper
